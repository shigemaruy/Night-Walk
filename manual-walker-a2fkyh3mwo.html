1ホーム画面に追加する

▶ Night Walker を開く
歩く人が使うアプリ／タップするとアプリが開きます
LINEの中では追加できません LINEでこのページを開いた場合は、右下の 「他のブラウザで開く」（iPhoneは「Safariで開く」）を押してから進めてください。

iPhone の場合

  1. Safari で、送られてきたURLを開く
  2. 下の 「▶ Night Walker を開く」 をタップ
  3. 画面右下の … をタップ
  4. 出てきたメニューの 共有 をタップ
  5. メニューを下にスクロールして ホーム画面に追加 をタップ
  6. 右上の 追加 をタップ
画面の下に ⬆️ が見えている場合 Safariの設定によっては、… ではなく共有ボタン ⬆️ が 直接表示されていることがあります。その場合は ⬆️ をタップして、 手順4は飛ばしてください。

Android の場合

  1. Chrome で、送られてきたURLを開く
  2. 下の 「▶ Night Walker を開く」 をタップ
  3. 右上の ⋮（メニュー）をタップ
  4. アプリをインストール または ホーム画面に追加 をタップ
  5. 確認画面で インストール をタップ

画面下に「アプリをインストール」の案内が自動で出ることもあります。その場合はそれをタップするだけです。

ホーム画面に、月と歩く人のアイコンができます。以降はそのアイコンから起動してください。ブラウザのタブから開くと、正しく動作しないことがあります。

位置情報を許可する（必須）

「許可」を選んでください アプリを開くと「現在地の使用を許可しますか？」と聞かれます。かならず 「許可」 を選んでください。

許可しないと、ペースチェック・天気・保護者への位置の共有 が使えなくなります。
まちがえて「許可しない」を選んでしまったら もう一度聞かれることはありません。次の手順で許可し直してください。

iPhone：
設定 → プライバシーとセキュリティ → 位置情報サービス → Safari のWebサイト → 「このAppの使用中」

Android：
設定 → アプリ → Chrome → 権限 → 位置情報 → 「アプリの使用中のみ許可」

正しく許可できていれば、アプリ上部に 気温と湿度 が表示されます。表示されるまで20秒ほどかかることがあります。

2最初の設定

アプリを開いたら、画面を一番下までスクロールして設定します。上から順に進めてください。

① お名前

名前を入れて 保存。LINEの通知に「〇〇さんが到着しました」と表示されます。

② 見守り共有（保護者と繋ぐ）

  1. ペアコードを作る をタップ（NW-8F3K2Q のようなコードができます）
  2. 保存 をタップ
  3. コードを送る をタップして、LINEで保護者に送る
  4. 今すぐ送信してテスト をタップ
  5. 「送信しました（○○:○○）」と出れば成功
ペアコードとは 親子を結びつける合言葉です。このコードを知っている人だけが、あなたの進捗を見られます。関係のない人には教えないでください。

③ 使い方のパターン

状況に合わせて、ペアコードの配り方を変えられます。

状況やり方
保護者が1人 作ったコードを、その方に送る
保護者が2人
（父・母など）		 同じコードを2人に送る
それぞれの端末に同じコードを入れれば、2人とも同時に見られます。互いに影響しません
兄弟で参加
（一緒に歩く）		 2人とも同じコードでかまいません
LINEには名前が入るので、どちらの連絡か分かります
兄弟で参加
（別行動）		 1人ずつ別のコードを作ってください
保護者は見たい方のコードに入れ替えて確認します
保護者が2人いる場合のおすすめ LINEに家族のグループを作っておくと、到着・出発の連絡を一度送るだけで2人に届きます。

④ 親の電話番号

緊急連絡用です。入れて 保存 すると、画面上の 📞 親に電話 が使えるようになります。

3歩いている間の使い方

これだけ覚えれば大丈夫

  1. 出発地点で、区間1のカードの 🚶 出発 を押す
  2. 次の休憩地点に着いたら、同じカードの 🏁 到着 を押す
  3. 休憩が終わったら、区間2のカードの 🚶 出発 を押す
  4. 以降、区間3・4…と同じことを繰り返す

ボタンを押すとその瞬間の時刻が記録され、LINEの送信画面が開きます。送り先を選んで送信してください。保護者への進捗共有は自動で行われます。

LINEは送り先を選ぶ必要があります ボタンを押すとLINEが開きます。送りたい相手やグループを選んで、送信ボタンを押してください。2回目以降は「最近の送信先」から選べます。

画面の構成

タブ内容
全体全9区間を一覧で表示
区間別1区間ずつ大きく表示（歩いている間はこちらが便利）
サマリーグラフと記録一覧。歩き終わったあとに

時刻を間違えたとき

カードの中の「実際出発」「実際到着」の欄をタップすると、時刻を直接直せます。右の × で消すこともできます。

4ペースチェック

📊 ペースチェック を押すと計測が始まります。そのまま1分ほど歩き続けてください。計測できると音が鳴って結果が出ます。

音で判定が分かります 画面を見なくても、鳴る音で速い・遅いが分かるようになっています。
結果音意味
順調ポーン、ピーン
（上がる2音）		予定どおり
速すぎピピピ
（高い音3回）		予定より1分/km以上速い
遅れブー、ブーー
（低い2音）		予定より1分/km以上遅い
押したあとは画面を消さないでください 画面を消すとGPSの記録が止まり、計測できません。計測中はアプリを開いたままにしてください。

画面が消えてしまうときは

設定の 画面を消さない をオンにすると、スリープしなくなります。電池の消費は増えるので、計測が終わったら戻すのがおすすめです。

5その他の機能

📞 親に電話
登録した保護者の番号にすぐ発信します。設定で電話番号を登録しておいてください。
📷 写真をLINEで送る
  1. 📷 写真をLINEで送る を押すとカメラが開きます
  2. 撮影すると、写真とボタンが画面に表示されます
  3. 📤 LINEなどに送る を押す
  4. 共有画面が開くので、LINE を選んで送信
時刻と今いる地点が、説明文として自動で付きます。

撮影のあと何も起きないように見えたら、画面を少し下にスクロールしてください。写真とボタンが出ています。

「LINEなどに送る」が無い、または共有画面が開かないときは
① 写真を保存 を押す（または写真を長押しして保存）
② 文面をコピー を押す
③ LINEアプリを開いて、写真と文面を送る
🗺️ 全行程のルートを見る
全10地点を地図上に表示します。ピンは S（出発）→ ①〜⑧ → G（ゴール）の順です。ピンをタップすると場所の名前が出ます。
🌤 天気・気温・湿度
画面上部に現在地の天気が出ます。タップすると天気アプリが開きます。夜の冷え込み対策にお使いください。
💾 記録を保存する（サマリータブ）
グラフと記録一覧をまとめたファイルを、端末に保存できます。

保存したファイルはブラウザで開けます。印刷メニューからPDFにすることもできます。
🎉 到着・出発時のメッセージ
ボタンを押すと、そのときの状況に合わせたメッセージが画面に出ます。

到着時：ねぎらいと祝福。経過時間・予定との差・平均ペース・残り距離が表示されます
出発時：励まし。次の地点とゴール予想が表示されます

スタートとゴールは特別な演出が出ます。音が鳴り、画面いっぱいにお祝いが表示されます。
ゴールの演出は、閉じるとそのまま記録画面に移ります。

メッセージを読んでから OK（LINEで知らせる） を押すと、LINEの送信画面が開きます。
自動では進まないので、ゆっくり確認してください。
🎁 アプリの更新
新しいバージョンがあると、アプリを開いたときに画面の上に案内が出ます。

更新 を押すと、数秒で最新版になります。
後で を押すと、その版については再度出ません。

入力した記録や設定は消えません。安心して更新してください。

画面の一番下に、いま使っているバージョンが小さく表示されています。
ペースの計画を切り替える
上部の 通常ペース / 1割速めペース で計画を切り替えられます。

入力した実際の時刻は共通なので、切り替えても消えません。

6行程設定（主催者向け）

計画切替の下にある 🛠 行程設定 から、コースや時刻を変更できます。参加者は触る必要はありません。

本番前に済ませてください 区間数を変えると、入力済みの実際の時刻が合わなくなることがあります。

設定できること

項目内容
基本情報タイトル、日付、2つの計画の名前
地点名前・緯度・経度。追加と削除ができます
距離手入力のほか、自動計算 で緯度経度から概算できます
時刻出発時刻、各地点の到着時刻、休憩時間
ペース分:秒/km で入力できます

時刻とペースの関係

  • 到着時刻を入れると → ペースが自動で計算されます
  • ペースを入れると → 到着時刻が自動で計算されます
  • 各区間の出発時刻は「前の地点の到着＋休憩」で自動的に決まります
保護者側にも自動で反映されます 行程を変えると、その内容が保護者のNW watcherにも自動で送られます。保護者側での設定は不要です。

設定を戻したいときは、一番下の 初期値（今回の行程）に戻す を押してください。

7困ったときは

いちばん大事なこと 画面を消すと、GPSの記録と保護者への自動送信が止まります。 ただし、到着・出発ボタンを押したときは必ず送信されるので、休憩地点ごとに保護者へ届きます。
症状対処
天気が出ない20秒ほど待つ。それでも出なければ、設定 → プライバシーとセキュリティ → 位置情報サービス で許可を確認
ペースチェックが「計測中」のまま1分ほど歩き続ける。建物の中や電波の悪い場所では測れません
音が鳴らないマナーモードを解除し、音量を上げる
LINEが開かないホーム画面のアイコンから起動しているか確認
保護者に届かない設定の「今すぐ送信してテスト」で確認。URLとペアコードが合っているか確認
記録を消したい画面下部の「入力した実際の時刻をすべてリセット」

電池を長持ちさせるには

  • モバイルバッテリーの持参をおすすめします
  • 使わないときは画面を消す
  • 「画面を消さない」は、ペース計測のときだけオンにする

8当日までの確認

  • ホーム画面に追加した
  • 位置情報を「許可」にした
  • お名前を登録した
  • URLとペアコードを保存した
  • 「今すぐ送信してテスト」で「送信しました」と出た
  • 保護者がNW watcherで受信できるか確認した
  • 親の電話番号を登録した
  • 屋外で10分ほど歩いて、ペースチェックが動くか確認した
  • LINEを1通送ってみた
  • モバイルバッテリーとケーブルを用意した
屋外での動作確認は必ず行ってください 当日に初めて使って不具合が見つかると、対処ができません。前日までに一度お試しください。
